# 📊 AI Business Intelligence Assistant

An AI-powered Business Intelligence platform that enables users to interact with PostgreSQL databases using natural language. The application leverages Google Gemini and LangChain to translate user queries into SQL and generate business insights through an intuitive Streamlit interface.

---

## 🚀 Features

- 💬 Natural Language to SQL Query Generation
- 🤖 Google Gemini Powered AI Assistant
- 🔗 LangChain SQL Agent Integration
- 🗄️ PostgreSQL Database Connectivity
- 📊 Interactive Streamlit Dashboard
- 🔒 Secure API Key Management using Environment Variables
- 📈 Business KPI Cards
- 💡 Example Business Analytics Queries

---

## 🛠️ Tech Stack

- Python
- Streamlit
- PostgreSQL
- SQLAlchemy
- LangChain
- Google Gemini API
- psycopg2

## ⚙️ Installation

```bash
git clone https://github.com/<your-username>/AI-Business-Intelligence-Assistant.git

cd AI-Business-Intelligence-Assistant

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py
```
